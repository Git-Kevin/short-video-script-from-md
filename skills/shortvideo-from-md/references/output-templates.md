# Output Templates

Use the smallest template that satisfies the request.

## Script Only

```text
Video positioning:
- Platform:
- Style:
- Duration:
- Core hook:

Spoken script:
[Hook]
[Beat 1]
[Beat 2]
[Beat 3]
[CTA]
```

## Script And Narration

```text
Video positioning:
- Platform:
- Style:
- Duration:
- Audience:

Title / cover copy:

Spoken script:

Clean narration:
[remove camera directions, keep only spoken lines]

Subtitle copy:
[short on-screen lines]
```

## Storyboard Package

```text
Video positioning:
- Platform:
- Style:
- Duration:

Shot-by-shot storyboard:
1. Duration:
   Visual:
   Spoken line:
   Subtitle:
   Asset suggestion:

2. Duration:
   Visual:
   Spoken line:
   Subtitle:
   Asset suggestion:
```

## Full Production Package

```text
Video positioning:
- Platform:
- Style:
- Duration:
- Core message:

Title / cover copy:

One-line summary:

Spoken script:

Clean narration:

Shot-by-shot storyboard:

Subtitle copy:

B-roll / asset suggestions:

BGM / SFX:

Ending CTA:
```

## Prompting Rules

- Keep `Clean narration` free of camera, editing, and subtitle notes.
- Keep `Shot-by-shot storyboard` specific enough for editing but short enough to scan quickly.
- If the user asks for multiple platform variants, keep the `Core message` fixed and only change hook, pacing, and CTA.
