# Title Types

Use these categories to build a balanced Xiaohongshu title set from Markdown content.

## Selection Guide

- Default to the six Xiaohongshu-native viral title types below.
- Treat them as the primary output framework for default title batches.
- Borrow from the secondary structural types later in this file when you need extra variety without drifting away from Xiaohongshu browsing habits.

## Emotional Resonance

Use when the source supports strong subjective reaction, relief, obsession, regret, amazement, or "this is so me" energy.

Common words:
- `who gets it`
- `so good`
- `obsessed`
- `cannot deal`
- `finally fixed`
- `wish I knew sooner`

Formula:
`<emotion word> + <object or scene> + <subjective payoff>`

Pattern examples:
- `Who gets it, this topic-selection method finally got me unstuck`
- `Wish I fixed my title workflow sooner, posting feels much lighter now`

## Pain-Point Tutorial

Use when the source solves a clear problem and can promise direct help, a walkthrough, or an actionable framework.

Common words:
- `step-by-step`
- `save this`
- `finally fixed`
- `walkthrough`
- `avoid these mistakes`

Formula:
`<pain point> + <solution promise>`

Pattern examples:
- `If you still cannot write XHS titles, this walkthrough will help`
- `New creators getting no clicks? Save this step-by-step guide`

## Numbered List

Use when the source contains several tips, methods, products, mistakes, or frameworks and benefits from low reading friction.

Common words:
- `3 things`
- `5 steps`
- `Top 10`
- `under budget`
- `keep rebuying`

Formula:
`<audience or topic> + <number> + <benefit or promise>`

Pattern examples:
- `Learn these 5 title moves first if you are new`
- `The 3 mistakes I keep seeing in educational content`

## Curiosity Reversal

Use when the source contains a reveal, contrast, hidden reason, or counterintuitive conclusion that creates an information gap.

Common words:
- `cannot hide this anymore`
- `finally found it`
- `turns out`
- `unexpectedly`
- `let's unpack this`

Formula:
`<curiosity trigger> + <half-spoken reveal>`

Pattern examples:
- `Turns out most weak titles fail at this exact step`
- `I finally found the reason educational posts feel boring`

## Audience-Targeted

Use when the source clearly serves a specific group, label, identity, schedule, body type, skin type, profession, or life stage.

Common words:
- `students`
- `warm skin tones`
- `office workers`
- `curvy`
- `pear shape`
- `sensitive skin`

Formula:
`<specific audience> + <pain point or result>`

Pattern examples:
- `New knowledge creators, this title framework is a strong place to start`
- `Busy office workers, you can still write clickable titles fast`

## Review Comparison

Use when the source compares options, judges product value, shows tradeoffs, or helps people decide what to buy, use, or trust.

Common words:
- `wins and fails`
- `full review`
- `budget alternative`
- `not worth it`
- `A vs B`

Formula:
`<objects being compared> + <decision tension>`

Pattern examples:
- `3 title approaches compared, which one fits educational accounts best?`
- `Template-sounding copy vs human-sounding titles, the gap is real`

## Universal Formula

When the source allows it, prefer:
`<target audience> + <pain point scene> + <emotion word or number> + <solution or payoff>`

Examples:
- `busy office workers + no time for makeup + done in 5 minutes + faux no-makeup tutorial`
- `warm skin tones + lipstick looks muddy on bare skin + these shades are stunning + lipstick picks`

## Secondary Structural Types

Use these when the user asks for them directly or when they help diversify a larger title pool.

## Result

Use when the source contains a visible payoff, transformation, or clear benefit.

Formula:
`<audience or scene> + <method> + <result>`

Pattern examples:
- `Commute outfits for petites | sharper proportions without trying too hard`
- `My beginner content workflow finally stopped the chaos`

## Pain-Point

Use when the source solves a frequent frustration, confusion, or inefficiency.

Formula:
`<pain point> + <solution direction>`

Pattern examples:
- `Working harder but still getting no clicks? Start with the title`
- `Your skincare may be failing because of this one step`

## Question

Use when the source contains a counterintuitive point or a strong teaching angle.

Formula:
`why/how + <counterintuitive problem or result>`

Pattern examples:
- `Why does useful content still feel invisible after posting?`
- `How do you make educational posts feel worth opening?`

## List

Use when the source offers multiple steps, habits, tips, or checkpoints.

Formula:
`<audience or topic> + <number> + <benefit>`

Pattern examples:
- `7 title angles that make educational posts easier to click`
- `5 things new creators should learn before posting daily`

## Anti-Pitfall

Use when the source warns against bad choices, mistakes, or misunderstandings.

Formula:
`<action or scene> + do not + <common pitfall>`

Pattern examples:
- `Do not post every day yet if your knowledge account is still messy`
- `Do not judge foundation by shade alone before buying`

## Comparison

Use when the source contains a noticeable contrast, before/after shift, or better/worse framing.

Formula:
`can/cannot + difference` or `difference between A and B`

Pattern examples:
- `The click-rate gap between strong titles and vague titles is real`
- `The difference between useful review posts and forgettable ones`

## Resonance

Use when the source is emotion-led, reflective, or centered on a recognizable state of mind.

Formula:
`<emotion or identity> + <point of view>`

Pattern examples:
- `What actually creates calm is not free time but control`
- `The older I get, the more I value clarity over noise`

## Audience-Targeted

Use when the source clearly serves a narrow audience segment.

Formula:
`for a specific audience + <advice or result>`

Pattern examples:
- `For people starting a side project: one honest reminder`
- `For warm-toned skin: check this before buying summer lipstick`

## Scene-Based

Use when the source is tied to a season, routine, event, or real-world scenario.

Formula:
`<scene or season> + <solution or payoff>`

Pattern examples:
- `A 5-minute early-morning makeup routine that still looks awake`
- `Travel photo outfits that look better on camera during holidays`

## Mixing Rule

For a default batch of 12 titles, use the six Xiaohongshu-native title types above with 2 titles each.

Prefer this default mix:
- `emotional-resonance`
- `pain-point-tutorial`
- `numbered-list`
- `curiosity-reversal`
- `audience-targeted`
- `review-comparison`

For expanded batches of 18 to 24 titles, keep the six default types and add structural support from:
- `result`
- `question`
- `anti-pitfall`
- `scene-based`
